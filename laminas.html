Como editar
• Arraste blocos daqui para a página (ou clique para adicionar).
• Arraste um bloco da página pelo ✥ ou pela borda para mudar de lugar.
• Clique no texto e digite.
• Ctrl+B deixa em negrito.
• Clique num bloco para ver a barra de ações (mover, largura, cor, desenho…).
• Arraste uma foto para reenquadrar; duplo clique troca a foto.
• Clique nas etiquetas de fase para ligar/desligar.
• Ctrl+Z desfaz.
